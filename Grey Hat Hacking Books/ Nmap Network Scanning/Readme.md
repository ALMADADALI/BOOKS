# 📘 Nmap Network Scanning – Official Guide by Fyodor

![Nmap Logo](https://nmap.org/images/nmap-logo-256x256.png)

## 🧠 About the Book

Written by the creator of Nmap, Gordon “Fyodor” Lyon, this book is the **ultimate guide** to mastering network scanning and reconnaissance. It goes beyond just options and flags — it teaches **how** and **why** to scan like a pro.

## 📚 Topics Covered

- Port scanning (SYN, FIN, NULL, Xmas, UDP)
- Nmap Scripting Engine (NSE)
- OS & version detection
- Firewall/IDS evasion
- Real-world examples
- Optimizing Nmap for large-scale scans

## 📌 Ideal For

Penetration testers, red teamers, sysadmins, bug bounty hunters, network security pros.
