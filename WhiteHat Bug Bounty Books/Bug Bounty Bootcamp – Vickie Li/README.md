# 🐞 Bug Bounty Bootcamp

A complete guide to finding and reporting web vulnerabilities. This book is beginner-friendly but powerful enough for intermediate hunters. Loaded with examples, methodologies, and bug bounty strategies.

## 📂 Topics Covered

- Introduction to Bug Bounties
- Setting up your lab environment
- Finding bugs like XSS, IDOR, SSRF, etc.
- Report writing & communication with programs
- Tools, tips, and mindset

## 🚨 Disclaimer

Educational use only. Use techniques responsibly.
