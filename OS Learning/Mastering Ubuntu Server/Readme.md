## 📚 Book Overview

> **Title:** Mastering Ubuntu Server  
> **Author:** Jay LaCroix  
> **Publisher:** Packt Publishing  
> **Edition:** 4th (2022)  
> **ISBN:** 978-1-80323-424-3

This book explores the powerful Linux server operating system, **Ubuntu Server 22.04**, and provides readers with the skills to manage, deploy, automate, and secure servers using real-world use cases.

---

## 🧠 What You Will Learn

- 📦 Master package management using APT and Snap
- 🔐 Manage users, permissions, and secure SSH access
- 🖧 Configure DHCP, DNS, and other network services
- ☁️ Deploy cloud infrastructure with AWS and Terraform
- 🐳 Run Docker and LXD containers
- ⚙️ Automate with Ansible
- 🛡️ Harden your server with firewall, Fail2ban, and encryption
- 🛠️ Troubleshoot and prevent disasters in production setups

---

## 🏗️ Topics Covered

- Ubuntu Server Deployment & Installation
- User and Group Management
- Networking, SSH, and DNS Configuration
- File Sharing (Samba, NFS), Rsync, SCP
- Web Hosting: Apache, NGINX, Nextcloud
- Database Management with MariaDB
- Virtualization with KVM & virt-manager
- Containers: Docker, LXD, Kubernetes (MicroK8s)
- Cloud: AWS EC2, Auto Scaling, AMIs
- Infrastructure-as-Code using Terraform
- System Security, Monitoring, and Troubleshooting
